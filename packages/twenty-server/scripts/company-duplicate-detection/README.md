# 기업 중복 후보 탐지

기업 원본 및 관계를 수정하지 않고, 후보 쌍과 일치 근거/충돌을 CRM 노트에 기록한다.
병합·삭제는 구현하지 않는다. 후속 병합은 관계 이관과 복구 기록을 포함한 소프트 삭제 방식으로 별도 구현한다.

## CRM 구성

- 워크플로우: `7ade9eb9-f72f-43e8-a9e8-ba36464ecc19`
- 초안 버전: `0c363487-5734-48d0-b603-15ff50642ce1`
- 코드 함수: `52d48234-0a8f-4f28-ac4a-4f621bf1ce6b`
- 코드 단계: `43b7d4a5-fa85-4d93-8d3c-40bf077f1190`
- 노트 생성 단계: `7b465931-c7e3-43c7-9c18-c687c4f0d388`
- 예약 설정: 매일 03:00 Asia/Seoul (18:00 UTC)
- 상태: **초안, 비활성**. 운영 `LOGIC_FUNCTION_TYPE` 비활성화로 테스트 실행이 시작 전에 실패했다.
- 실패 실행: `0fbac713-6d89-4650-9840-bf4fcbaeaa25`

워크플로우 스키마 검증은 통과했다. 운영 코드 실행 환경이 준비된 후 전체 실행(조회 및 노트 저장)을 성공시키고 활성화해야 한다. 운영 보안 설정은 이 작업에서 변경하지 않았다.

## 최초 후보 탐지 결과 (2026-09-08)

운영 코드 실행이 비활성화되어 있어, CRM 커넥터로 기업을 100개씩 조회한 뒤 로컬에서 동일한 `analyze` 함수를 실행했다. 최초·최종 총건수, 수집 건수 및 고유 ID가 모두 6,625개로 일치함을 확인했다.

- 후보 228쌍, 후보에 포함된 기업 409개
- 우선 검토 0쌍 / 충돌 검토 21쌍 / 일반 검토 207쌍
- CRM 보고서: https://crm.gainge.com/object/note/cafbd098-6159-40ac-a2d7-b26aef3e3fd1
- 기업·고객·문의·계약 및 기존 노트 연결 변경/병합/삭제: 0건
- 검증: 단위 테스트 7개, TypeScript 검사, CRM 보고서 재조회

이 결과는 전용 워크플로우의 성공 실행 결과가 아니다. 예약 배치는 초안이며 아직 실행되지 않는다.

## 탐지 규칙

- NFKC/공백/대소문자를 정리한 기업명, 명시적 법인 표기를 제거한 기업명 비교.
- 도메인은 프로토콜/경로/www를 정리하고 공용 이메일/소셜 서비스의 대표 호스트 제외.
- 대표 전화번호와 기업 이메일 비교. 일반명/빈값은 이름 매칭에서 제외.
- 회사 이름에 포함된 일반적인 `주`를 무조건 제거하지 않음. 지점 표기도 보존.
- 후보는 **쌍 단위**로 작성. 연결된 후보 전체를 하나의 회사로 간주하지 않음.
- 이름과 추가 근거가 일치하면 우선 검토. 도메인/전화/이메일/DRI/책임자/주소가 충돌하면 충돌 검토.
- 모든 후보는 사람의 검토가 필요하며 자동 병합 적격성을 의미하지 않음.
- 영문 별칭/오타 유사도/보조 연락처/사업자번호/연결 이력은 v1 탐지 범위 밖.

## 실행과 검증

`detect.ts`는 별도 패키지 없이 CRM 함수 환경에서 실행되며, 런타임에 주입된 앱 인증으로 동일 CRM의 읽기 GraphQL 쿼리만 호출한다. 인증을 코드에 저장하거나 로그로 출력하지 않는다.

200개씩 최대 4개 페이지를 병렬 조회하고 총건수·레코드 수·고유 ID·마지막 총건수를 검증한다. 50,000개 기업 또는 10,000쌍을 넘으면 결과를 잘라 성공 처리하지 않고 중단한다. 조회는 단일 DB 스냅샷이 아니므로 병합 전 최신 정보 재검증이 필요하다.

후보 보고서는 실행마다 새 노트로 남긴다. 노트 저장 단계 자동 재시도는 꺼져 있다. 실행 실패를 확인하고 수동 재시도할 때 기존 보고서 생성 여부를 먼저 확인한다.

```sh
node --experimental-strip-types --test packages/twenty-server/scripts/company-duplicate-detection/detect.test.mjs
./node_modules/.bin/tsc --noEmit --skipLibCheck --target ES2022 --module nodenext --moduleResolution nodenext packages/twenty-server/scripts/company-duplicate-detection/detect.ts
```
