# 커밋 분할·검토 프롬프트

아래 블록을 Cursor / Claude 채팅에 복사해 사용하세요.

---

현재 작업 중인 변경 사항을 검토하고, 커밋 단위로 나눠 주세요.

## 목표

- git status 기준 미커밋 변경을 논리적 순서로 분할
- 각 커밋이 독립적으로 리뷰 가능하도록 구성
- 불필요한 파일, 누락 파일, lint/typecheck/test 이슈도 함께 점검

## 티켓 정보

- 티켓: AX-XXX
- 브랜치: {브랜치명}
- 커밋 메시지 언어: 한글
- 커밋 실행: 아직 하지 말 것 / 지금 커밋해 주세요

## 작업 특성 (해당하는 것만 남기기)

- [ ] 프론트만
- [ ] 백엔드만
- [ ] 스키마 / 메타데이터 / 마이그레이션 포함
- [ ] 백엔드 + 프론트 혼합

## 커밋 분할 우선순위

`GAINGE_WORKFLOWS.md`의 **커밋 분할 순서**와 **커밋 분할 규칙**을 따르세요.
(작업 특성에 맞는 섹션: 백엔드+프론트 혼합 / 프론트만)

## 출력 형식

### 1. 커밋 전 검토 결과

- 지금 커밋 가능한지 (예/아니오)
- 블로커 (typecheck, lint, 누락/불필요 파일)
- 권장 선행 작업

### 2. 추천 커밋 표

| # | 커밋 주제 | 한 줄 요약 | 상세 변경 사항 |
|---|-----------|------------|----------------|
| 1 | AX-XXX ... | ... | • file.ts — ... |

### 3. (요청 시) 실제 커밋

- 위 표 순서대로 git add → git commit
- 커밋 후 git log --oneline 확인
- working tree 깨끗한지 확인

## 검증 명령 (가능하면 실행)

`GAINGE_WORKFLOWS.md`의 **커밋 전 체크리스트**를 따르세요.

---

## 예시: 프론트만 (AX-192)

| # | 커밋 주제 | 한 줄 요약 |
|---|-----------|------------|
| 1 | 타입·상수 기반 | 도메인 타입과 상수 정의 |
| 2 | 첨부 조회·출처 유틸 | 필터/출처/방향 판별 순수 로직 |
| 3 | GraphQL·활동 조회 확장 | GQL 필드 + activityHasAttachments |
| 4 | 첨부 데이터 훅 확장 | useAttachments 연관 첨부 조회 |
| 5 | 공통 컴포넌트·훅 | 액션/아이콘/출처 라벨 |
| 6 | Files 탭 | 리스트/그리드/외부 링크 카드 |
| 7 | 노트·태스크 UI | 첨부 클립 아이콘 |

## 예시: 백엔드 + 프론트 (이메일 첨부)

| # | 커밋 주제 | 한 줄 요약 |
|---|-----------|------------|
| 1 | 스키마·메타데이터 기반 | DB/메타데이터 구조 |
| 2 | 이메일 첨부 저장 모듈 | 핵심 저장 로직 |
| 3 | 수신 메일 Import 확장 | Gmail/Outlook/IMAP |
| 4 | 발신 메일 첨부 처리 | outbound 연동 |
| 5 | 타임라인 API 확장 | hasAttachments API |
| 6 | 프론트 — 파일 탭 | 이메일 유래 첨부 표시 |
| 7 | 프론트 — 이메일 UI | 스레드/상세 첨부 UI |
